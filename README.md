# Scientist-Animation

Scientist Animation built using HTML, CSS, and JavaScript.

![Screenshot of Scientist Animation](./Screenshot%202024-12-09%20181238.png)

## Overview

A lightweight, responsive animation showcasing a scientist character created with vanilla HTML, modern CSS, and a touch of JavaScript. This project is ideal for learning CSS animations, transforms, and how to combine them with simple JavaScript to control timing or interactivity.

## Features

- Pure HTML/CSS animation with optional JavaScript enhancements
- Clean, well-structured code for easy learning and modification
- Works in modern browsers with no build step required

## Live Preview

To preview the animation locally:

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Scientist-Animation.git

2. Open `index.html` in your browser, or serve the folder with a simple static server, for example:

   python -m http.server 8000

   Then open http://localhost:8000 in your browser.

## Files

- `index.html` — markup and structure for the scene
- `style.css` — styling and animation rules
- `script.js` — (optional) JavaScript for any interactive behavior
- `Screenshot 2024-12-09 181238.png` — project screenshot (shown above)

## How to Use / Customize

- Edit `style.css` to change colors, sizes, and animation durations.
- Modify `index.html` to add or remove elements in the scene.
- Add interactivity (hover, click, or timed effects) in `script.js`.
